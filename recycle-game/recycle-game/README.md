# 분리수거 대작전

컨베이어 벨트 위로 굴러오는 쓰레기를 알맞은 통에 넣는 아케이드 게임이에요.
보스전, 아이템, 너구리 도둑, 피버 타임, 8비트 배경음악이 들어 있어요.

## 플레이
GitHub Pages를 켜면 `https://<내아이디>.github.io/recycle-game/` 에서 바로 할 수 있어요.

## 조작
- 통 누르기 / 키보드 1~6: 맨 앞 쓰레기를 그 통으로
- 끌어다 놓기: 아무 쓰레기나 잡아서 통에
- 라벨 떼기·헹구기·아이템: 눌러서 (스페이스)
- P / Esc: 일시정지

파일은 `index.html` 하나뿐이라 다른 설치가 필요 없어요.
